# Расчёт дистанционных защит (ДЗ)

Веб-приложение для визуализации расчётов дистанционных защит: характеристики
ступеней в плоскости R-X, импорт протоколов ПК БРИЗ (`.dz`) и наложение замеров,
несколько расчётов с переключением по вкладкам. Все вью — производные от единой
структуры данных (`src/model`).

## Стек
- Vite + React + TypeScript
- Zustand — единый стор (`src/model/store.ts`)
- d3-scale — оси графика R-X (собственный SVG-рендер, `src/components/RXPlot.tsx`)
- Парсер `.dz` без зависимостей (`src/dz/parseDz.ts`)

## Команды
```bash
npm install
npm run dev     # http://localhost:5173
npm run test    # парсер .dz + поток данных стора
npm run build
```

## Формат .dz
Бинарный протокол: записи вида `тег(4 байта ASCII) + |Z|(float32 LE) + угол°(float32 LE)`.
Теги — токи (`IA..I0`), напряжения (`UA..U0`), сопротивления (`ZA..Z0`).
Точка замера: `R = |Z|·cosφ`, `X = |Z|·sinφ` (контур `ZAB`). Парсер сверен с
парными `.xlsx` (например, `Чувств.dz` → `ZAB = 13.91 ∠ 76°`).

## Структура
- `src/model/` — типы и стор (единая структура данных)
- `src/dz/` — парсер протоколов
- `src/geometry/` — построение полигона характеристики
- `src/components/` — график, вкладки, таблицы уставок, список замеров, импорт
- `src/data/seed.ts` — демоданные из листа `Концепт`

Примеры в корне (`*.dz`, `*.xlsx`, `Приложение.xlsx`) — исходная спецификация и
фикстуры для тестов.
